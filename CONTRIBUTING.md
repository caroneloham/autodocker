# Contribuer

Les corrections de bugs, tests, améliorations d'accessibilité et propositions documentées sont bienvenus. Ouvrez d'abord une issue pour un changement important afin de discuter de son périmètre. Pour une modification de code, créez une branche, ajoutez les tests utiles, puis vérifiez `go test ./...` avant de proposer une pull request.

Ne joignez jamais de clé d'API, mot de passe, base de données, projet client, fichier Compose privé ou journal contenant des informations sensibles. Les exemples doivent utiliser des valeurs fictives et minimales.

Toute contribution aux éléments couverts par ce dépôt est proposée sous les conditions de [LICENSE](LICENSE). Les composants tiers restent soumis à leurs licences propres. Une modification ne doit pas présenter une version dérivée comme une version officielle.
